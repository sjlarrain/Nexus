# Warm Intro

Swipe-based professional referral app (US market): two-way matching, chat with
adaptive reply suggestions, and in-app 30-minute coffee-chat booking.

**Stack:** TypeScript · Next.js (App Router) · Firebase (Auth, Firestore, Storage) · Vercel
